# 递归三部曲刷题计划

## 目标

这份计划的核心目标不是单纯刷题，而是刻意练习递归三部曲：

1. 确定递归函数的参数和返回值
2. 确定终止条件
3. 确定单层递归逻辑

前期重点：
- 先把递归写熟
- 先形成手感
- 先学会分析函数定义
- 暂时不要过度追求总结的完美

## 每做一题都要问自己的 4 个问题

1. 这个递归函数的定义是什么？
2. 参数为什么这样设计？
3. 终止条件是什么？
4. 当前这一层递归到底做了什么？

---

## 递归题分类意识

做题时尽量判断这题属于哪一类：

### 1. 遍历型递归
特点：
- 更关注“每个节点要做什么”
- 常见写法是 `void dfs(...)`
- 常配合结果集 `res`

典型题目：
- `144`
- `94`
- `145`
- `257`

### 2. 返回值型递归
特点：
- 更关注“子问题返回什么”
- 常见写法是 `int`、`boolean`、`TreeNode` 等返回值
- 通过 return 组织答案

典型题目：
- `104`
- `100`
- `110`
- `236`

## 刷题建议

- 每道题先口述递归三部曲，再动手写代码
- 写完后回头总结这题属于哪一类递归
- 前期允许套模板，先模仿再内化
- 不要一开始就追求总结得特别完美
- 先做够数量，再做归类和反思
